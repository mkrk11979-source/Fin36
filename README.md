# тихо. — MVP личных финансов

Мобильное веб-приложение на React + TypeScript + Vite. На текущем этапе не требует платных API или сервера.

## Уже есть

- Первый запуск с вводом начального баланса (он не считается доходом).
- Дашборд с текущим балансом и расходами за календарный месяц.
- Добавление операции естественным текстом с простым локальным распознаванием.
- Экран проверки операции до сохранения.
- Ручное заполнение и редактирование суммы, описания, даты, типа и категории.
- Создание новых категорий без дубликатов по точному совпадению.
- Удаление с подтверждением.
- Сохранение в `localStorage` браузера.

## Важно

- Это **локальный прототип**, а не готовый защищённый финансовый сервис.
- Данные хранятся только в текущем браузере на текущем устройстве. Очистка данных браузера может их удалить.
- Распознавание сейчас основано на простых правилах и не является AI.
- Фото чеков, серверная база, авторизация, Telegram Mini App validation и бот ещё не подключены.
- Не вноси реальные чувствительные данные, пока не появится серверная часть и защита.

## Запуск локально

Нужен Node.js 20 или новее:

```bash
npm install
npm run dev
```

Для проверки сборки:

```bash
npm run build
```

## Бесплатная публикация для проверки

Можно загрузить проект в GitHub и импортировать репозиторий в бесплатный статический хостинг, поддерживающий Vite (например, Cloudflare Pages или GitHub Pages). Для GitHub Pages может понадобиться настройка `base` в `vite.config.ts`, если сайт размещается в подпапке репозитория.

## Структура

- `src/App.tsx` — интерфейс и состояние приложения.
- `src/recognition.ts` — временное распознавание текста по правилам.
- `src/types.ts` — типы данных.
- `src/styles.css` — адаптивный тёмный интерфейс.
